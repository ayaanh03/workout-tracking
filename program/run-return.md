# Run return and recovery

Apply before [ordinary progression](run-progression.md). Preserve the normal prescription and record temporary work/return paths separately in [running state](../state/running.json).

## Missed work, illness and return


Skip missed work. Measure gaps separately per run type since its last completed interval workout. Planned assessment substitutions/reductions alone cause no return penalty. Before temporary work, save return reason and intended normal level; temporary sessions/tests updating actual dates cannot erase the path.

| Trigger | Prescription once recovered |
|---|---|
| Isolated scheduling miss, gap ≤14 days, no illness/fatigue | Clear streak; repeat prior normal prescription without credit to validate dose. Controlled effort and reported normal next-day recovery permit counting subsequent normal workouts. Failure within cap or poor recovery → reduced path below. Appropriate slowing alone does not fail dose validation; save slower target. Uncertain conditions/missing recovery leave validation pending. |
| Option C, illness, or 15–28-day gap | Clear counts/comfortable credit; one level below last successful normal level, bounded by calibration and weekly ceiling. No prior success → calibration. |
| Gap >28 days | Calibration; rebuild toward original starting levels (Tuesday 12 / Friday 18). |

Start no faster than previous target and slow to respect cap. With no global fatigue flag, normal effort/recovery at a return dose permits at most one restored level next time. Short returns restore only toward prior normal level. Return/restoration earn no hits; count subsequent full normal workouts only after intended normal dose is validated and global fatigue clears. If not tolerated, hold lower/omit. An isolated scheduling miss may use the narrow test exception in [assessments](assessments.md).

## Symptoms and recovery

Immediately shorten/skip for gait-changing pain, worsening joint/tendon symptoms, illness or unusual fatigue. Do not wait for a second miss.

Two successive attempts at the same prescription with reported poor next-day recovery trigger a one-level temporary cut and clear counts, even if pace was met. A well-recovered attempt breaks the pattern. If calibration is poorly tolerated, omit hard work and review.

For an **isolated run-recovery issue**, freeze that run's progression; require two well-recovered exposures at the reduced dose before restoring toward normal. Temporary dose may fall between levels. Neither temporary work nor restoration earns credit; validate normal dose before subsequent counting.

**Global fatigue takes precedence:** [adjustments](adjustments.md) prescribes seven days of C, reassessment, then an actual observation week at return doses. Flag remains active: no faster pace, more minutes, longer cycling, discretionary lift progression, singles or tests. Prescribed recovery-to-observation transition is allowed. Clear only on completed relevant sessions with acceptable recovery/performance; an empty week is insufficient. Afterwards make one substantive restoration/progression at a time. Persistent symptoms override every timetable.
