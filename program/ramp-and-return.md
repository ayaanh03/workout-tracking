# Lifting stage, reductions and return

Use each day's explicit A/B/C–D set counts; [current state](../Tracker.md) supplies the achieved stage. Normal D totals are 83 core sets + 2 forearm sets, or +4 when eligible. Totals are checks, never targets after restrictions.

| Stage | Core effort | Advance only after |
|---|---|---|
| A | About 3 RIR; calibrate loads | A completed manageable week |
| B | About 2–3 RIR | A completed manageable week |
| C | Full baseline sets, about 2–3 RIR | A completed manageable week |
| D | Day-table RIR; eligible final 0–1 sets | Earn ordinary progression |

A manageable week means stable execution, settling soreness, no worsening joint/tendon symptoms, and acceptable subsequent priority sessions. Missing evidence holds the stage; a later explicitly manageable completed week can release that hold. Never skip C based on the calendar. During A–C keep loads stable once effort is appropriate; the added sets already progress the dose. W4/W9 singles do not move if D is delayed.

## Effective sets and effort

1. Begin with achieved-stage allocation. In normal D include deliberately approved additions.
2. Apply persistent local omissions/ceilings last. Stage advancement or a trial cannot restore a cut. See [adjustments](adjustments.md).
3. Return A–C suspends added-set trials: original stage allocation capped by local limits. Reintroduction needs fresh review.
4. Only M2/M3/M4/T2/T3/T5/S1/S2/S3 may use a final 0–1 set, only in eligible normal D. Local rollback, fatigue, reduction or return suspends it. An added set becomes the sole final 0–1 set in that slot.

Warmups are excluded from totals. Two unilateral sets per arm count as two, not four. Normal unmodified day totals:

| Stage | Mon | Wed | Thu | Sat core + forearms | Sun | Weekly |
|---|---:|---:|---:|---:|---:|---:|
| A | 11 | 7 | 12 | 6 + 0 | 11 | 47 |
| B | 16 | 12 | 18 | 9 + 2 | 13 | 70 |
| C/D | 19 | 14 | 21 | 11 + 2 | 18 | 85 |
| Eligible D, W6+ forearms | 19 | 14 | 21 | 11 + 4 | 18 | 87 |

Use current ab limits in recovery state. The October 24 bodyweight-only substitution permits two sets in each ab slot: stage A is 11/7/12/6/11 = 47. Its two-set ceiling and minimum 3 RIR persist through stage advancement until reviewed; reduced-work rules may lower the dose further. Documented substitutions or omissions do not by themselves invalidate a manageable week.

## Assessment weeks

W5 retains achieved-stage lifting when recovered; only endurance routinely reduces. A planned first test in W3/W4/W5 omits Wednesday calves. A cancelled test never restores that omitted work. This planned omission alone does not block stage advancement; actual post-test recovery still matters. W5 after an early attempt uses Option B when recovered, with usual achieved-stage calves; no second first test. W4's single remains subject to its own eligibility. See [assessments](assessments.md).

## Reduced lifting — W10 or Option C

Apply new local rollbacks and saved return-stage limits first. Global fatigue cancels unresolved added-set trials. Snapshot the **effective normal** set vector: stage baseline + adopted additions + still-active approved trials, with local cuts. Pending return A–C uses that stage, not an old D dose. Scheduled W10 alone does not cancel a trial.

Apply once to the snapshot:

- Omitted slot: zero.
- Other core slots: `max(1, floor(normal sets / 2))`.
- Incline replaces halving: M1a/M1b `min(normal sets, 1)`; T1 `min(normal sets, 2)`. Omitted remains zero.
- Forearms: zero. About 4 RIR, lower load as needed; no 0–1 sets or single.
- A test also omits Wednesday calves.

Unmodified full baseline gives 38 sets, or 36 with test-calf omission; A/B gives 32, or 31 with that omission. Recalculate after restrictions. Repeated/overlapping reductions use the appropriate normal snapshot once, never halve the reduced result again. Tightened restrictions apply immediately.

## Illness or lifting gap

Once training is appropriate, count from the **pre-interruption last completed lift** to first return attempt. First matching row wins:

| Situation | Initial return stage |
|---|---|
| More than 28 days away, any reason | A |
| Non-illness break ≤14 days | Established stage, existing limits retained |
| Fully resolved mild illness ≤7 days, with ≤7 days without lifting | C or lower last tolerated stage |
| Other illness break ≤28 days, or non-illness gap 15–28 days | B, or A if B never tolerated |

No established tolerated stage means A. Symptoms/reduced capacity may require less work or more time off.

Before any return attempt, including reduced/Option C work, save the historical last-lift date, last tolerated stage, reason, initial return stage and active return-stage limit. Temporary attempts cannot erase/recalculate that limit upward; a later interruption may tighten it.

Advance at most one stage from the stage actually completed after an explicitly manageable return week. Reduced work does not qualify. An appropriate completed observation week can qualify, but advancement waits for fatigue clearance. Update the active limit after each authorized advance; preserve initial stage as history. Clear the return restriction when entry to D is authorized, retaining local/global restrictions. Never jump back to an old stage or restore trials automatically.

Return work has no singles/0–1 sets and earns no loading, plateau or run-pace credit. Runs have separate [return rules](run-progression.md). Option C uses the [global observation process](adjustments.md#global-fatigue); stricter gap limits still apply. W10 without illness/fatigue ends at next-block review, not an automatic new program.
