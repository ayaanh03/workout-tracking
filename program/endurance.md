# Endurance prescriptions

Use current targets in [running state](../state/running.json); these are initial values. Apply [run progression](run-progression.md), [assessment](assessments.md), injury and recovery limits before the calendar ceiling.

| Run | Initial target | Final-rep RPE cap | Recovery between reps only |
|---|---|---|---|
| Tuesday | 6:50/mi (410 s/mi) | 8/10 | 3 min easy jog/walk |
| Friday | 7:25/mi (445 s/mi) | 7/10 | 2 min easy jog/walk |

- Warmup: 10 min easy running; up to 5 extra minutes if needed. Cooldown: 5–10 min easy jog/walk. Include all running in mileage.
- Easy pace guide: 8:30–9:30/mi, conversation comfortable; slower allowed. No HR/cadence targets, strides, finishing sprints, standalone easy runs or planned work bouts under one minute.
- Keep recovery mode and route/setup comparable. Default treadmill grade is 1%; record another fixed grade. Extra rest disqualifies progression.
- Slow an unsuitable target immediately; never force the RPE cap to preserve a hit.
- A representative 5K at unrounded average pace `P` seconds/mile sets Tuesday to `round5(P−5)`, Friday to `round5(P+30)`, where `round5(x) = 5 × floor(x/5 + 0.5)`. For 21:30, `P = 1290 × 1.609344 / 5 = 415.210752`, giving 410/445. Initial setup uses W1 doses; later tests use the reset rule in [test resets](run-credit.md#tests).

## Cycling

Only after Wednesday/Saturday lifting: RPE 3/10 (acceptable 2–4), comfortable full-sentence conversation. Advance duration only when the previous dose left subsequent lifting/running acceptable; otherwise hold the last tolerated duration. Global fatigue freezes increases. Option C allows at most 15 comfortable minutes; rest is allowed. [Adjustments](adjustments.md) controls observation and return.

## Running mileage ceiling

Maximum **15 miles/week**, including all running in warmups, recoveries and cooldowns. Recalculate the complete week's upper distance after any pace, work or warmup change; compare **unrounded** distance with 15. Fixed minutes at a faster pace add distance. Walking does not add running mileage.

If over: remove Friday's last work rep and recalculate, repeating as needed. Before trimming below 12 Friday work minutes, use 2 × 6; if that still cannot fit, omit Friday. Recheck the whole week and shorten/omit Tuesday too if necessary. No added easy miles or catch-up. Mileage cuts earn no progression credit and do not replace the saved normal prescription; restore only when the full week fits and recovery permits. In a test week keep the test at exactly 5 km: reduce the other run or choose B instead of truncating/adding a test.
